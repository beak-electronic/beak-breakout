# BrEAK•out

Kleines Breakout-Spiel im Browser – eine einzige, eigenständige HTML-Datei (`index.html`), ohne externe Abhängigkeiten.

**Spielen:** https://beak-electronic.github.io/beak-breakout/

## Steuerung
- ← → : Schläger bewegen
- Leertaste (oder ↑): Ball starten
- P / Esc: Pause

## Extras
- **B** – großer Ball (10 s), zerstört dunkle Steine mit einem Treffer
- **E** – Erde: Boden unter dem Schläger, hält einen Ball auf
- **A** – breiterer Schläger (15 s)
- **K** – kleine, schnelle Bälle + 2 Extra-Bälle

10 Level, 3 Leben, Highscores werden lokal im Browser gespeichert.
